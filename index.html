    Acantharian morphology
    Parent radiates this many; children inherit half so the parent radial pattern dominates.
    Per-spine length variation. 0 = all spines identical; 1.5 = some very short, some very long.
    Replaces straight spines with 5-segment helical chains. Adjacent spines twist out of phase, so where they bunch near the body they spatially interleave like cinnamon-twist strands.
    Number of times the emergence-spiral winds around the body from pole to pole. Sequential spines are spatial neighbours, so the curve is visible as a seashell-style spiral painted on the sphere.
    Number of acantharian generations: 1 = single creature, 2 = main + babies at every spine tip, 3 = + grand-babies (heavy).
    Per-child size variability (multiplicative). 0 = identical clones; 1 = wide small/medium/large mix.

    Coralline morphology
    Per-level blend toward the radial direction from origin. 0 = children follow parent direction exactly; 1 = children point straight outward. Higher values make the bouquet fan tighter into a half-dome silhouette.
    Fraction of leaf tips that grow a hybrid terminal element — randomly assigned per leaf from three types: flower-bell (calyx + radiating petals), fern-fiddlehead curl, and anemone-polyp bristle cluster. Mixing botanical and animal forms gives the creature an alien, no-Earth-analog feel.
